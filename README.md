# ATV_ESTACIONAMENTO

Simulador de um estacionamento inteligente que abre e fecha as cancelas automaticamente quando um carro chega perto usando sensores ultrassônicos para medir a distância dos carros, servos para mover as cancelas, e um display LCD para mostrar quantas vagas ainda têm. Usando obuzzer para dar alerta quando o carro está muito próximo.
